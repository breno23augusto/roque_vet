# Roque Serviços Veterinários - SPA

Site institucional da Roque Serviços Veterinários.

## 🚀 Tecnologias

- HTML5
- CSS3 (com variáveis CSS para fácil personalização)
- JavaScript Vanilla (sem frameworks pesados)
- AOS (Animate On Scroll) para animações
- Swiper.js para o carrossel de depoimentos
- Font Awesome para ícones
- Google Fonts (DM Sans e DM Serif Display)

## 📁 Estrutura de Arquivos

```
roque/
├── index.html        # Página principal (SPA)
├── style.css         # Estilos separados (opcional)
├── logo_texto.svg    # Logotipo da marca
└── README.md         # Este arquivo
```

## 📱 Funcionalidades

- **Design Responsivo** - Mobile-first, funciona em todos os dispositivos
- **Navegação Suave** - Scroll animado entre seções
- **Menu Mobile** - Toggle para dispositivos móveis
- **Animações** - Efeitos de entrada com AOS
- **Formulário de Contato** - Integração direta com WhatsApp
- **Carrossel de Depoimentos** - Slideshow automático
- **Hover Effects** - Interactions saborosas

## 🚀 Como Usar

1. Copie todos os arquivos para uma pasta
2. Abra `index.html` no navegador
3. Para GitHub Pages:
   - Crie um repositório no GitHub
   - Faça commit dos arquivos
   - Ative GitHub Pages nas settings
   - O site estará em `https://seu-usuario.github.io/repo/`

## 📝 Customização

Para mudar as cores, edite as variáveis CSS em `:root` no arquivo `index.html`:

```css
:root {
    --azul-rox: #9A99FF;
    --off-white: #FAF5F0;
    --preto: #000000;
    --cinza: #A3A3A3;
}
```
